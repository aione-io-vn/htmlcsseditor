# Soạn & Nộp bài HTML/CSS qua mạng LAN

Phần mềm miễn phí cho phòng máy Tin học THPT: học sinh soạn HTML/CSS (gợi ý code, xem kết quả ngay)
và nộp bài vào máy giáo viên qua mạng LAN, không cần Internet.

Kho này **chỉ chứa bản đóng gói** để tải về và để phần mềm tự cập nhật.

## Tải về

Vào mục [Releases](https://github.com/aione-io-vn/htmlcsseditor/releases), tải file
`HTMLEDITOR-<phiên bản>.zip` mới nhất, giải nén vào `D:\PHANMEM\HTMLEDITOR`, rồi làm theo
`README.md` bên trong (mục "Cài đặt tại phòng máy").

Đã cài rồi thì không cần tải lại: trang quản trị tự báo khi có phiên bản mới, bấm "Cập nhật ngay".
